🌸 Glossier Website Clone

A responsive front-end clone of the Glossier beauty brand website built using HTML, CSS, and JavaScript.
This project replicates the UI design, layout, and basic interactive functionality of the original website.

📌 Project Overview

This project is a static front-end clone of the Glossier website created for learning and practice purposes.
It focuses on:

Responsive design

Clean UI implementation

DOM manipulation using JavaScript

Modern CSS styling techniques

⚠️ This project is made only for educational purposes and is not affiliated with Glossier.

🛠️ Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and layout

JavaScript (Vanilla JS) – Interactivity and dynamic features

✨ Features

✅ Fully responsive design

✅ Navigation bar with dropdown / hover effects

✅ Product showcase section

✅ Hero banner section

✅ Add to cart UI (if implemented)

✅ Smooth scrolling / interactive buttons

✅ Clean and modern layout
